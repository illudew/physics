Hello-World 👋

这是一个用于演示的示例仓库，包含了项目的基本结构、构建脚本与单元测试。 你可以直接 fork 它作为自己项目的起点。

✨ 特性

  • 零依赖，开箱即用
  • 内置开发服务器与热更新
  • 完整的单元测试与 CI 工作流
  • 支持 TypeScript 类型提示

🚀 快速开始

# 克隆仓库
git clone https://github.com/octocat/Hello-World.git

# 安装依赖
npm install

# 启动开发服务器
npm run dev

📁 目录结构

.
├── .github/        # CI 与 Issue 模板
├── src/            # 源代码
├── tests/          # 单元测试
├── package.json
└── README.md

🤝 贡献

欢迎提交 Issue 与 Pull Request。提交前请先运行 npm test 确保所有测试通过。
